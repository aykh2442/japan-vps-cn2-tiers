## CN2、9929、CMIN2 分别管什么

答案很直接：这三条线分别对应电信、联通、移动三家运营商的精品骨干网，所谓"三网优化"就是三家运营商的流量各自走自己的优质回程线路。

- **CN2（AS4809）**是中国电信的国际精品骨干网，其中 CN2 GIA 是优先级最高的一档。它和普通 163 线路（AS4134）的区别不在理论带宽，而在拥塞时的待遇——GIA 被降级、被丢包的概率明显更低。
- **AS9929** 是联通的精品网，对应的是默认国际出口 AS4837。这两条线在凌晨可能看不出差别，晚八点到十一点的差距则可能是"能打开"和"超时"的区别。
- **CMIN2 / CMI（AS58807 / AS58453）**是移动的国际优化网络。移动用户基数最大，历史上国际出口质量也最被吐槽，CMIN2 就是针对这个问题的补丁。

只优化电信的日本 VPS 很常见，只写"CN2 回程"、联通移动走公网的更多。三家都走精品回程的方案成本高，报价通常也不客气。

结论先给：这个日本节点对电信和联通用户接近"给多少跑多少"，移动用户下行正常、上行被压得厉害。

这组数字怎么用，取决于你拿机器干什么：

- **建站、跑 API、看视频、做下载分发**——影响很小。用户访问你的站点主要是下行，移动下行 174–568Mbps 完全够用。
- **直播推流、大文件上传、需要稳定上行回国内**——移动用户会很难受，30–46Mbps 的上行在 4K 推流面前很紧张。电信、联通用户不受这个限制，400Mbps 以上的上行足够。

延迟方面，官方文档标称日本节点到中国大陆典型 RTT < 50ms，同时注明"实际延迟随本地 ISP、时段和网络状况变化"。第三方实测口径差别不小：有资料给华东 30–50ms、华南与西部 50–80ms，也有资料直接写 70–100ms。合理的预期是 40–100ms 区间，具体到你所在城市，只能自己 ping。

顺带提一句测评里发现的细节：5201 端口的 iperf3 被屏蔽了，想自己复测要换端口，别以为网络不通。

## 三条只写在文档里、但会直接影响使用的规则

### 1. 600 Gbps 防护是付费附加，默认只有尽力而为

官网首页把 "up to 600 Gbps mitigation capacity" 放在功能列表里，很容易被读成标配。官方文档写得很清楚：所有实例默认只有 best-effort 基础清洗，600 Gbps 专业清洗是需要付费的附加服务，价格要联系客服。

更关键的是黑洞机制。当攻击影响到同网段其他客户时，系统会自动给这个 IP 上 null route，持续 30–60 分钟，自动解除，**无法人工干预**。这段时间里该 IP 的所有进出流量全部丢弃，服务实质中断。如果你做的是容易被攻击的业务（游戏服、跨境站），这一点必须提前算进去，而不是出事才发现。

### 2. "24 小时无理由退款"的实际门槛比字面窄

官方文档写明退款仅限首次购买，续费订单不适用。以下情形都不退：

- 超过 24 小时的订单
- 续费订单
- 因违反 ToS 被终止的服务
- 已使用的账户余额
- 因 DDoS 被黑洞的 IP
- 24 小时内流量使用超过 10GB（写在 ToS 里）

另外，原交易产生的支付手续费会从退款金额里扣除，不是全额退回。到账时间：支付宝 1–3 个工作日，信用卡 5–10 个工作日，加密货币 1–3 个工作日。

这个政策依然有实际价值——它给了你一个 24 小时的验证窗口。但用法要对：**别在窗口内跑大流量压测**，10GB 很容易超；把时间花在 ping、traceroute 和晚高峰速度测试上，那才是决定要不要留的关键。

### 3. 超流量限速 20 KB/s，但可以买流量包续命

流量跑满不停机、不额外扣费，而是限速。第三方测评写的限速值是 20 KB/s——这个速度对任何面向真实用户的业务都等于停摆，只能等下一个计费周期重置。

官方提供了另一条路：自助购买流量包，100GB $6、500GB $30、1TB $60、2TB $120，即时计入当月配额。但**流量包只在当前计费周期有效，不结转到下月**，长期不够官方自己也是建议升级套餐。
